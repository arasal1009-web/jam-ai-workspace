# Music Production — Claude/Codex/Hermes Handoff

If another assistant works on this project, read `AGENTS.md`, `README.md`, and `PROJECT_BRIEF.md` first.

## Fast context

Jude has a Suno AI subscription with 2,500 monthly credits. He wants to use those credits intentionally to create music, especially focus/study/work background music that can become YouTube playlists. Secondary uses include OST/cinematic cues and inspiration-driven music experiments.

## Default task flow

1. Research YouTube niches using `workflows/youtube-music-niche-research.md`.
2. Rank niches by demand, competition, saturation, repeat-listen potential, and production feasibility.
3. Generate Suno prompts using `workflows/suno-monthly-credit-production.md` and `templates/suno-prompt-template.md`.
4. Save drafts in the repo; do not spend credits or publish.
5. End with a handoff: files read, files changed, blockers, recommended next action.

## Boundary

This project is manual-first. No cron, containers, YouTube uploads, Suno credit usage, or external account changes unless Jude explicitly approves the exact action.
