# Suno Prompt Template

## Prompt ID

`YYYY-MM-DD-niche-###`

## Use case

- Focus / study / coding / reading / sleep / OST / cinematic cue / other:

## Style field

```text
Instrumental [genre/subgenre], [mood], [setting/atmosphere], [instrumentation], [production texture], [tempo/BPM if useful], [dynamic arc]. Designed for [study/work/focus/etc.], loopable, non-distracting, no vocals.
```

## Lyrics / structure field

```text
[Instrumental]
[Intro: quiet texture, establish mood]
[Section A: main groove/theme, steady and minimal]
[Section B: gentle variation, no sudden changes]
[Interlude: sparse, atmospheric]
[Section A reprise: warm and loopable]
[Outro: soft fade, unresolved enough to loop]
[End]
```

## Exclude styles

```text
vocals, lyrics, rap, spoken word, harsh drums, aggressive drops, sudden loud transitions, busy lead melody, distorted clipping, chaotic percussion
```
