# YouTube Music Niche Research Workflow

**Purpose:** Find low-competition, high-demand YouTube niches for AI-generated background/focus/study/music playlists.

## Manual-first workflow

1. Define 10–20 candidate niches.
2. For each niche, collect current YouTube search evidence.
3. Score demand, competition, repeat-listen potential, Suno feasibility, Jude brand fit, and playlist expansion.
4. Rank the niches and identify the top 3 test lanes.
5. Pass the selected lanes to the Suno Prompt Producer.

## Candidate keyword expansion pattern

Start broad, then narrow by:

- user state: ADHD focus, deep work, exam study, coding, reading, writing;
- setting: rainy café, night library, dorm room, city night, tropical rain, fantasy tavern;
- sound: no vocals, soft piano, calm synthwave, tape warmth, ambient pads, subtle drums;
- duration/format: 1 hour, 2 hours, playlist, seamless loop;
- mood: cozy, dark academia, cinematic, hopeful, melancholic, calm.

## Data to collect per keyword

| Field | Notes |
|---|---|
| Keyword | Exact phrase searched |
| Top results | 10–20 relevant videos if possible |
| Views | Use visible view counts; mark missing if unavailable |
| Age | Publish date/age |
| Channel concentration | Are results dominated by a few huge channels? |
| Recent breakout? | New/recent videos with strong views |
| Saturation signs | Many identical mixes/thumbnails/titles |
| Small-channel visibility | Are smaller/newer channels ranking? |
| Listener intent | Study/work/sleep/coding/writing/background |
| Production fit | Can Suno plausibly produce it? |

## Scorecard

Score 1–5. Explain briefly.

| Metric | 1 | 5 |
|---|---|---|
| Demand | few plays/weak intent | strong plays and clear intent |
| Competition inverse | dominated/saturated | room for small/new channels |
| Repeat-listen potential | novelty only | good for looping/playlists |
| Suno feasibility | hard to generate cleanly | easy to generate many variants |
| Jude brand fit | weak/irrelevant | aligned with focus/creative goals |
| Playlist expansion | one-off | can become series/playlists |
